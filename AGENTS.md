# Instruksi Coding Agent

Baca file `PRD.md` sebelum membuat atau mengubah fitur apa pun.

## Aturan Utama

- Project ini menggunakan Laravel full-stack.
- Gunakan Blade dan Livewire untuk frontend.
- Gunakan autentikasi session bawaan Laravel.
- Jangan menggunakan JWT untuk autentikasi website.
- Jangan menggunakan React, Vue, Next.js, atau Express.js.
- Gunakan MySQL sebagai database.
- Ikuti struktur, business rule, dan acceptance criteria di `PRD.md`.
- Jangan mengubah struktur database tanpa membuat migration.
- Gunakan Form Request untuk validasi kompleks.
- Gunakan Policy atau middleware untuk authorization.
- Jalankan test setelah menyelesaikan fitur.
